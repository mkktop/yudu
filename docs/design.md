# 雨读 Yudu · Orbital 改版

雨读是本地与云端漫画阅读器。新版以「故事，自有引力」为视觉方向：深空背景、冷青交互、淡紫辅助信息和轨道几何。阅读流程围绕找到漫画、接着阅读和管理来源展开。

[打开离线设计预览](orbital-preview.html) · [查看设计总览](orbital-overview.png)

预览包含七个界面，可切换深色/浅色和示例阅读状态。预览使用虚构的测试漫画、示例页数与原创几何插画，是设计参考；不是原生 App 的截图，也不连接任何真实账号。

## 信息结构

| 入口 | 主要内容 | 常用操作 |
| --- | --- | --- |
| 书架 | 续读卡、封面墙、搜索、阅读状态 | 续读、查看详情、排序、切换列表、筛选来源 |
| 书库 | 本地文件/文件夹、WebDAV、天翼云盘 | 添加来源、重新扫描、移除来源 |
| 统计 | 今日页数与目标、连续阅读、七天柱图、阅读热力 | 查看近半年/一年轨迹 |
| 设置 | 外观、阅读默认、护眼、每日目标、缓存容量 | 修改全局偏好、清理缓存 |

主路径：**书架 → 作品详情 → 阅读器**。续读卡直接进入目标章节。添加入口在书架右上角和书库页面共用一个导入面板。书库管理从设置中移出，并保留快捷跳转。

## 各页面行为

### 书架

- 首屏介绍当前漫画总量与在读数量，不展示虚构推荐或在线人数。
- 最近在读的作品为主续读卡，其他作品横向排列；已读完和全部未读的作品不占用续读区。
- 续读卡与详情页共用目标章节规则：最近未完成章节 → 第一未完成章节。读完一话后，卡片指向下一话。
- 筛选包括全部、未读、在读、已读完；可再按书库来源筛选，标题搜索与筛选叠加。
- 排序支持最近阅读、最近添加、名称。网格/详细列表及排序记住上次选择。
- 搜索无结果时提供清除筛选；首次空书架展示明确的添加按钮与支持格式。
- 下拉刷新重新扫描。扫描中显示状态，避免看起来卡住。

### 作品详情

- 封面、来源、阅读状态、已读话数和全书百分比集中在作品卡。
- 阅读按钮清楚区分开始、继续、再次阅读；全书完成后再次阅读从第一话开始。
- 云端作品提供整部离线缓存、缓存进度和取消操作，下载失败显示可重试提示。
- 目录按卷分组，可折叠、倒序、只看未读及定位续读。长目录使用惰性布局。
- 「进入章节」与「标记已读」是相邻控件，避免嵌套按钮误触。标记未读会删除该话进度。
- 重置进度和删除导入副本均有确认，说明保留/删除的内容。

### 添加与云盘连接

- 分为本地添加和云端连接两组：文件导入、文件夹授权、WebDAV/NAS、天翼云盘。
- 只允许 ZIP、CBZ、PDF 文件导入，文件夹继续支持已有散图扫描。
- 进行中显示进度提示并阻止误关。成功与失败用不同图标、标题和颜色反馈。
- WebDAV 接受 HTTP(S)，无协议时补全 HTTPS；完整校验地址后才能连接。账户密码由单独输入框提供。
- 云端目录空与网络读取失败分别呈现。加载时禁用重复导航；连接凭证沿用现有钥匙串机制。
- 来源只显示「已添加」，不把未验证的网络状态写成「在线」。

### 沉浸阅读

- 阅读器隐藏底部 Tab，内容保持黑色背景，工具栏使用同一套冷青线性图标。
- 顶栏负责退出和阅读设置；底栏提供上下话、直接跳页、页码滑条、目录、模式、适配和护眼。
- 边界章节和加载中的操作自动禁用；跳页需要有效的 1…总页数，空输入及越界不能提交。
- 中间点按显示/隐藏工具栏，保留既有翻页手势、条漫和 PDF 连续阅读。
- 模式、方向、适配按作品记忆；阅读器内可直接调亮度、暖色和自动夜间护眼。
- 加载失败可重试或返回。

### 阅读统计与设置

- 今日目标默认为 30 页，可在设置中调整为 5…200 页。
- 环形进度最多填满一圈，达到目标有文字反馈，不依赖颜色表达。
- 七天柱图与近半年/一年热力图来自真实阅读流水；无记录时显示零值和引导。
- 「累计」使用完整流水，不再截断为最近一年；今天尚未阅读时，连续记录仍可从昨天计算。
- 流水基于阅读器翻页进度，不代表阅读时长。手动标记已读不增加阅读页数。
- 缓存面板解释容量与离线保护规则，清理全部缓存有明确确认。正在缓存时先取消下载任务再清理。

## 视觉规范

| 语义 | 深空模式 | 晨光模式 |
| --- | --- | --- |
| 页面背景 | `#080E18` | `#F1F5F8` |
| 卡片表面 | `#111D2C` | `#FFFFFF` |
| 次级表面 | `#19283A` | `#E6EEF4` |
| 主文字 | `#EAF3FC` | `#142333` |
| 辅助文字 | `#91A6BC` | `#52667B` |
| 主交互 | `#74E6DB` | `#006D68` |
| 辅助强调 | `#B4A1F5` | `#6A4DB3` |
| 边线 | `#2A3D50` | `#CAD7E2` |

- 页面边距 20 pt，卡片内边距 16–22 pt，封面圆角 10–12 pt，面板圆角 22 pt。
- 主按钮至少 50 pt 高，图标操作通常为 44×44 pt，阅读工具至少 48 pt 高。
- 主文字使用系统字体与 Dynamic Type，英文微型标题只用于辅助识别；关键功能保留中文说明。
- 轨道线、背景网格与光晕为静态装饰，正文不叠加扫描线、不闪烁。真实漫画封面优先，无封面时才显示程序化轨道封面。
- 支持系统、浅色、深色。新安装默认深色，已有外观偏好保持。阅读器与阅读设置使用深色以保持画面和控制对比度。
- 图标按钮补充 VoiceOver 标签，统计图格子提供日期/页数描述。真实设备的大字体、横屏与 iPad 手势仍需要专项手动验收。

## 实现与验证

设计组件位于 `yudu/Features/Shared/DesignSystem.swift`。业务模型未改动，不引入新的数据库字段或第三方运行依赖。新增偏好使用 UserDefaults，保留已有阅读记录、书库配置与钥匙串。

`tools/make-orbital-icon.py` 使用 Pillow 生成新的不透明 1024×1024 应用图标；生成图片已经提交，不影响普通 Xcode 构建。

GitHub Actions 的 `iOS build and reading checks` 执行：

1. 用真实 SwiftData 内存库运行 `tests/QueriesChecks.swift`，覆盖续读章节、部分进度、完成/未读切换、清空进度、历史统计和 WebDAV 地址。
2. Xcode 编译 iOS Simulator App（无签名，构建时覆盖最低系统为 iOS 18，源项目的发行系统设置不变）。
3. `tools/simulator-smoke.sh` 生成原创本地测试图，启动模拟器，走过扫描、详情、单页、恢复进度、条漫、续读书架、书库、导入、统计、设置与浅色书架，截图保存在 workflow artifact。
4. 额外编译 Release，确保自测钩子不进入发行配置。

模拟器 smoke test 仅使用本地散图文件夹，未用真实账号验证 WebDAV/NAS 与天翼云盘登录。保留这些功能的既有协议实现。签名、真机、云端认证与真实文件规模仍需在对应设备/账号上验收。

可在装有 Xcode 的 Mac 上运行：

```sh
xcrun swiftc -swift-version 5 -parse-as-library \
  yudu/Model/Entities.swift yudu/Model/Queries.swift \
  yudu/Core/WebDAV/WebDAVAddress.swift tests/QueriesChecks.swift \
  -o /tmp/yudu-checks
/tmp/yudu-checks

xcodebuild -project yudu.xcodeproj -scheme yudu \
  -configuration Debug -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath build/ci CODE_SIGNING_ALLOWED=NO \
  IPHONEOS_DEPLOYMENT_TARGET=18.0 SUPPORTED_PLATFORMS=iphonesimulator build

bash tools/simulator-smoke.sh
```

## 本次范围

已实现的是原生 UI 与本机阅读流程。没有添加云端进度同步、漫画内容推荐、AI 解读、付费系统或通知服务，界面也不假装这些服务已经接通。
